      Want a male or female voice?

      On Android, Chrome uses the voice Android's text-to-speech is set to for each accent, so male or female is picked there:

      1. Open Android Settings and search Text-to-speech.
      2. Tap the gear next to Speech Services by Google.
      3. Install voice data → English (United States) (or another accent).
      4. Pick a voice; tap it to hear it. Then reopen this app.

      Each accent in the list above can have its own voice, so you can set, say, US to female and UK to male and switch here.
